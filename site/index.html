One evidence store, three front ends

Reviews, questions and proposed tests about Mathlib's probability theory live in one place: the evidence store of this repository, as records in git. Each front end below reads the same records against the same dataset of Mathlib, so a review written once shows up in all three, with its status against the current code.

The site

Mathlib's probability theory read as a referee does: claims, what they rest on, every declaration with its reviews, and coverage under the reader's choice of whose reviews count.

trust's front end

The dependency tree of a declaration, with what reviewers accepted marked as trusted and what changed since a review marked as such.

One claim's page

The strong law of large numbers: the statement, what it rests on, and every review, question and reply about those declarations, as threads.

Add to it

Anyone with a GitHub account can review a declaration, report a problem, ask a question or propose a test, with the issue forms (or the buttons on each front end). A bot turns the issue into a record, and the three front ends are rebuilt. Records are never anonymous: each names the GitHub account it came from, and an AI agent's are labelled as such.
